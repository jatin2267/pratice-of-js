# Practice of JS

> A collection of foundational JavaScript practice scripts covering variable declarations, scope differences, type conversions, and console inspection methods.

---

## Features

- **Variable Declarations & Mutability (`variable.js`)**:
  - `const`: Immutable identifier bindings and reassignment restrictions.
  - `let`: Block-scoped reassignable variables.
  - `var`: Scope demonstration illustrating pitfalls in block and functional scoping.
  - Handling uninitialized variables (`undefined`).
  - Structured output inspection using `console.table()` for multi-variable state monitoring.
- **Data Type Conversions & Casting (`datatypeconversion.js`)**:
  - Evaluating runtime types using `typeof`.
  - Explicit boolean conversions (`Boolean()` truthy/falsy evaluation with numbers).
- **Console Output & Execution**:
  - Interactive logging with `console.log()` and `console.table()`.

---

## Tech Stack

- **Language**: JavaScript (ES6+)
- **Runtime**: Node.js / Browser JavaScript Console

## How to Install and Run

Run the scripts directly using [Node.js](https://nodejs.org/):

1. **Clone the repository:**
   ```bash
   git clone https://github.com/jatin2267/pratice-of-js.git
   cd pratice-of-js
   ```

2. **Run any script with Node.js:**
   ```bash
   node variable.js
   node datatypeconversion.js
   node console.js
   ```

3. **Or run inside browser DevTools:**
   - Open any browser tab, press `F12` to open DevTools, select the **Console** tab, and paste the code to execute immediately.
